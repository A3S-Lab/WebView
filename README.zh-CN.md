[A3S Code](https://github.com/A3S-Lab/Cli) 的本机窗口伴侣。
它拥有两个必须保持独立于终端的桌面表面：

- 调整 RemoteUI 和受信任的本地报告 WebView 窗口的大小；和
- 位于物理屏幕顶部的透明、始终位于顶部的 Agent Island
  中心。

它还为需要多个应用程序的应用程序提供了本机工作区主机
一个窗口内隔离的 WebView。主机将应用程序外壳保存在
一个 WebView 并将生成感知的本地或远程资源 WebView 放置在
该外壳提供的类型化矩形。这避免了 iframe 嵌入限制
不允许未经验证的导航或过时的资源事件。

普通链接仍会在用户的浏览器中打开。无法启动任一本机
Surface 永远不会阻止 A3S Code TUI 的运行。

## 安装

```bash
brew install a3s-lab/tap/a3s-webview
# or build from source:
cargo install --git https://github.com/A3S-Lab/WebView
```

已发布 `a3s` 发布档案和 Homebrew `a3s` 公式安装此
CLI 旁边的二进制文件。独立公式仍然可用于源或
CLI 的 Cargo 安装。

## 用法

```text
a3s-webview --url <http(s)://…|file://…> [--width N] [--height N] [--title T]
            [--header 'Name: Value']… [--token-env NAME] [--no-auth]

a3s-webview --agent-island --snapshot <absolute-path> --lock-file <absolute-path>

a3s-webview --workspace-host --url <http(s)://…|file://…>
            [--width N] [--height N] [--title T]
            [--allow-file-root <absolute-path>]…
```

- `--url`（RemoteUI 模式）— `http://`、`https://` 或受信任的本地`file://`
  报告。
- `--width` / `--height` — 窗口大小，以逻辑 px 为单位（限制为 240–4000 × 180–3000）。
- `--title` — 窗口标题（默认`A3S RemoteUI`）。
- `--header 'Name: Value'` — 额外的请求标头，可重复。
- `--token-env NAME` — 保存会话令牌的环境变量（默认`A3S_OS_TOKEN`）。
- `--no-auth` — 不播种任何身份验证令牌。
- `--agent-island` — 在单独的、
  无框操作系统窗口。快照和锁定路径必须是绝对同级路径
  每个用户的私有目录。共享咨询锁只允许一个岛屿进入
  即使多个 TUI 发布者请求，也可以为当前用户进行处理。一个
  没有确切的非空闲 A3S 生命周期或已识别的新鲜快照
  编码 Agent进程关闭助手；新流程行触发并保持
  岛屿还活着。
- `--workspace-host` — 加载应用程序 shell 并公开版本控制
  `a3s.workspace.v1` JavaScript 桥。 shell 可以打开本地应用程序，
  远程 HTTP(S)，或显式将本地文件资源作为子 WebView。
  每个打开、边界、遮挡、关闭和桥接消息都携带一个资源
  id 和世代。主机拒绝过时的世代、经过认证的 URL、
  不支持的方案、未经批准的来源、不安全的文件路径、过大
  消息和未经请求的弹出导航。特权 shell 桥是
  固定到确切的初始路径和查询，而不是页面上的每个页面
  相同的起源。内容 WebView 在加载时保持隐藏，用简短的内容显示
  尊重简化运动设置的原生过渡，并被破坏
  当关闭或主机退出时。

## 工作区主机桥

shell 在脚本运行之前接收`window.a3sWorkspaceHost`。它发送
带有 `postMessage(command)` 的 JSON 命令并通过以下方式接收生命周期事件
`a3s-workspace-event``CustomEvent`。选择加入的本地应用程序
类型化桥接收`window.a3sWorkspaceView`；他们只在之后调用`ready()`
它们的交互状态已安装，`fail(message)` 对于有界可恢复
错误，以及 `postMessage(payload)` 模式拥有的应用程序消息。

当类型化以下内容时，主机不会将网络负载视为应用程序就绪状态：
桥已启用。它等待应用程序握手并报告错误
30秒后。主机到视图的消息保存在有界本机 FIFO 中，直到
类型化的应用程序报告已准备就绪，然后按顺序交付。这可以防止
初始修订版本在捆绑包启动或导航期间丢失，无需
创建无限的内存接收器。

shell 可以发出 `workspace.occlusion`，而受信任的兄弟覆盖层是
打开。遮挡从演示和输入中删除活动的子 WebView
而不破坏它或导航离开。清除遮挡恢复相同
安装视图而不重播其入口动画。准备就绪，待定
消息和代理工作继续独立进行；陈旧的世代无法隐藏
或恢复较新的内容。

远程资源默认为其初始来源并且不接收任何桥接。一个
调用者必须显式添加源或在开放中启用类型化桥
政策。 `javascript:`、嵌入式凭证、任意文件访问和原始
本机后端名称从不被接受。本地应用路由也拒绝
编码分隔符、编码点段和双编码遍历输入。

运行原生双源烟门验证输入的本地内容，保留
跨遮挡状态，第二个环回源上的远程资源，
同源导航，拒绝跨源导航：

```bash
./scripts/workspace-host-smoke.sh
```

该装置将一个类型化的本地应用程序作为子 WebView 打开，发布一个
准备就绪前进行工件修订，准备就绪后观察有序交付，
不断练习本机边界更新，然后将其替换为
来自 `127.0.0.1:4319` 的无桥远程表面。远程表面可能
在该原点内导航，但导航回 shell 原点是
在任何请求到达 shell 服务器之前被拒绝。

## Agent Island 用户界面

该岛是由这个独立的Tao/Wry 助手实现的。它离线嵌入
平台WebView中的HTML、CSS和JavaScript；它不渲染通过
`a3s-tui`，A3S GUI 包、React 或 Next.js。紧凑型`480 × 72`药丸
展开为有界、可滚动的 `560 × 360` 细节表面。其透明的
本机窗口添加 48 个水平逻辑像素和 32 个垂直像素
每侧都流血（`576 × 136` 折叠，`656 × 424` 展开）。的
宽阔的光环在出血中褪色为透明，而不是暴露
本机窗口的矩形裁剪边界。塌陷的表面显示
主要任务、代理、工作区或可操作的原因、状态和实时情况
经过的时间。它的有界度量尾部最多显示三个项目，按优先顺序排列
如部分数据健康状况、需求计数、运行计数、直子进度、
最近的结果，然后是总代理。这可以保留紧急证据和飞行中的证据
无需将紧凑的表面变成完整的活动面板即可看到。
当需要关注多行时，可以发出批准或输入请求
在保留故障之前，解锁工作将成为主要紧凑行。
自动注意力扩展不会窃取键盘焦点；扩展的
窗口变得可聚焦，以便用户可以操作控件并类型化回复
直接在岛上。

在 macOS 上，帮助程序将 `NSScreen.safeAreaInsets` 与两个一起读取
辅助顶部区域。居中的硬件凹口使表面从
物理屏幕边缘具有方形顶角，同时布局紧凑的内容
在畅通无阻的左右翼中。当需要时，紧凑的宽度会增加
适合缺口，每侧 12 个逻辑像素间隙，以及两个 160 像素
内容之翼；因此，212 像素的凹口在内部产生 `556 × 72` 表面
`652 × 136` 本机窗口。扩展后的宽度至少为 `560` 像素，并且
如果紧凑型缺口安全宽度更大，也会增加。

紧凑摘要下方的可见句柄可启动平台的本机窗口
拖。成功拖动后，两秒居中传球不再移动
岛屿，缺口融合样式被删除，展开/折叠保持移动
表面的顶部中心，而不是将其捕捉回显示器边缘。

用户首选项默认为启用并由 A3S Code保留。
`/island on|off|status` 通过 TUI 进行控制。扩展视图还提供
`Turn off`，在助手之前写入相同的私有选择退出标记
退出； `/island on` 恢复表面。

每行都使用原始的机器人几何形状，其调色板源自
代理供应商，而不是复制的徽标或吉祥物。确切的生命周期行显示代理，
任务、状态、工作空间和已用时间；终端持续时间冻结在
报告完成时间。批准行显示其经过清理的、有限的原因
并使用更大的 `Allow` / `Always` / `Deny` 按钮。实时补助金仅添加
控制拥有 TUI 当前可以执行的操作：批准操作，`Stop`
父流，`Cancel` 用于正在运行的子流，以及直接回复编辑器
符合条件的确切父行。推断的流程行永远不会接收控制。

细节视图是一个关注工作台，带有实时`All`、`Needs you`、
`Running`和`Recent`计数。 `Needs you` 涵盖批准等待、输入等待、
和失败； `Recent` 涵盖已完成、失败和取消的结果，因此
故意的失败属于双方。过滤子项会将其父项保留为
标记了上下文，每个家长都报告根据其直接孩子的情况
总计。仅过程证据仍然在 `All` 下明确推断，并且
出现在`Running`下，因为已识别的进程是实时运行的证据；
它永远不会伪装成权威的生命周期状态。

每个以前未见过的可操作批准或输入身份选择
`Needs you` 并在不激活岛屿的情况下扩大岛屿一次。续
具有相同控制令牌的心跳在手动崩溃后不会重新打开它，
稍后的新请求也会这样做。手动过滤器选择保持稳定，直到出现新的过滤器
注意身份到来。

任何精确的 `planning` / `working` 行或公认的编码 Agent进程都可以
动画的多层多色霓虹灯边框。减少运动模式保持
静态颜色边框，背景 WebView 接收低频直接
重新绘制，以便 WebKit 计时器节流不会冻结呼吸效果。

生命周期运动与渲染的表面同步。本机窗口
保持隐藏状态，直到第一个快照布置完毕，然后是紧凑岛
从固定的框架中缓入。扩展准备透明本机主机
首先，将可见几何图形留给一个 WebKit 时间线；塌陷完成
缩小透明主机之前的时间线。活动行不是
在任一变形期间重建，并且细节面板保持包含油漆直到
几何形状稳定下来。合成器是在原生生长之前准备好的，而
连续的霓虹灯和模糊工作暂停打开、调整大小和关闭。冗余
会跳过本机帧更新和未更改的 WebView 边界，因此定期
重新居中不会强制进行额外的页面布局。自动注意力扩展
等待打开完成，关闭甚至会保留中断的调整大小
直到其最长的合成器转换完成。背景分类
仅暂停连续的 neon 工作，而不暂停有界的生命周期转换。
减少运动偏好使每个生命周期变化立即发生。

控制点击和回复是根据最新的清理快照进行授权的
并作为有界的、版本化的请求写入私有同级队列。回复
限制为 1,000 个字符/4 KiB； `Enter` 发送并`Shift+Enter` 插入
换行符。在批准期间，回复会排队正常跟进，并且不会
含蓄地赞同或否认。在 Unix 上，队列是`0700`，请求文件是
`0600`。目标 TUI 根据其目标重新验证短暂的、一次性的授权
使用现有的之前的当前会话、活动和工具/任务上下文
提交、批准、中断或子取消路径。

## 认证

A3S OS Web 应用程序通过 `localStorage` (`access_token` /
`auth_token`)，而不是 cookie — 因此新打开的 WebView 将登陆登录
页。在导航之前，助手通过巧妙的初始化来播种这些键
脚本，从 TUI 导出的 `A3S_OS_TOKEN` 环境变量中读取令牌（所以它
从未出现在 `argv` / `ps`）。

## 平台支持

|平台|后端 |笔记|
|---|---|---|
| macOS | WKWebView |系统框架；本机岛无需进入 Dock 即可加入 Spaces 和全屏辅助窗口，读取居中凹口的显示安全区域几何图形，并支持本机拖动。 |
| Linux | WebKitGTK |需要`libwebkit2gtk-4.1`； X11 支持顶部中心/保持上方提示。标准 Wayland 可能会忽略全局布局。 |
|窗户 |网页视图2 |运行时随受支持的 Windows 版本一起提供；该岛位于任务栏和 Alt-Tab 列表之外，在折叠时保持非激活状态，并在展开以进行直接交互时接受焦点。 |

发布工作流构建所有 CLI 目标。在没有安装助手的地方，
RemoteUI 降级为系统浏览器，并且跳过 Agent Island 启动。
每个拉取请求都在 Linux 上本地运行严格的 Clippy 和完整的测试套件，
macOS 和 Windows； Linux 还验证格式、rustdoc 和包内容。
